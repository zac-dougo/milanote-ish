# Milanote-ish

A local Mac app for storyboarding and collecting references on freeform boards.

The planned stack is Tauri, React, TypeScript, and SQLite. The interface uses a colour-block design, with mixed-content cards and nested boards. No accounts, cloud dependency, or subscription limits.

## Project documents

- [Implementation specification](docs/v1-spec.md)
- [Scope and decisions](docs/product-scope.md)
- [Domain glossary](CONTEXT.md)

User-supplied visual references are kept locally and excluded from the public repository.

Development is starting with a small working slice to validate the desktop stack, local saving, and resource use before implementing the full specification.
